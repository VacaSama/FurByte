# FurByte - A Digital Companion <br> (Student Project)
This is FurByte, a ASP.NET Core program that I will be working on as part of my student work for my Advanced .NET Course.
FurByte is a digital companion that you can feed, bathe, and interact
with daily.

### Features :
- Built with C#, .NET, ASP.NET Core, and EF Core
- SQL Server Database
- More Features will be listed as the project grows :) <br> Thanks for your patience!
### Coming Soon :
- Pet Sprites with Emotions - Content, Happy, Sad, etc
- Progress Bars using Bootstrap - 0 to 100 in value, your progress bar hits 0, the pet will run away or be taken. Mood Decay Logic.
- Rehoming Pet Feature (opt..) - The option to rehome your pet if you're unable to care for them, just give them to a friend you trust and see how they're doing later on.
- Planning with GitHub integration
### Getting Started :
1. Clone the Repo/Start in Visual Studio
2. Run update_database using Entity Framework to initialize FurByteDB (NOT YET IMPLEMENTED)
3. Launch the app
